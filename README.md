# Modern Flutter Portfolio | Ubaidullah

A high-performance, visually stunning developer portfolio built with Flutter. This project features a sophisticated dark-themed UI with glassmorphism, custom particle systems, and a unique terminal-inspired storytelling component.

## 🚀 Key Features

- **Interactive Terminal Widget:** A geeky, functional-style terminal for an immersive "About Me" experience.
- **Dynamic Skill Visualization:** Glassmorphic cards with animated proficiency indicators and interactive hover states.
- **Advanced Animations:** Fluid, premium interactions powered by `flutter_animate` and custom `RepaintBoundary` optimizations.
- **Responsive Architecture:** Fully optimized layout that adapts seamlessly to Mobile, Tablet, and Desktop Web.
- **Clean Architecture:** Organized into `core` (breakpoints, themes) and `presentation` (pages, widgets) layers for scalability.

## 🛠️ Tech Stack

- **Frontend:** Flutter (Web & Mobile), Dart
- **State Management & Routing:** GoRouter, Provider
- **Design:** Glassmorphism, Radial Gradients, Custom Grid Painters, and Particle Systems.
- **Integrations:** Firebase, Google Maps API, Node.js, and MySQL.

## 📱 Featured Projects

- **Fit Mind:** A comprehensive health & activity tracker featuring real-time biometric charts and Firebase backend.
- **Life Link:** A community-driven blood donation platform with real-time routing and Google Maps integration.

## 📂 Project Structure

```text
lib/
├── core/           # App constants, themes, and responsive breakpoints
├── presentation/
│   ├── pages/      # Main layouts (Home, Projects, Experience)
│   └── widgets/    # Reusable components (Navbar, Terminal, SkillCard)
└── assets/         # Images, custom fonts (Plus Jakarta Sans), and CV
```

## ⚙️ Getting Started

### Prerequisites
- Flutter SDK (`>=3.5.0`)
- Dart SDK

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/ubaidullah/portfolio_project.git
   ```
2. **Install dependencies:**
   ```bash
   flutter pub get
   ```
3. **Run the project:**
   ```bash
   flutter run -d chrome
   ```
